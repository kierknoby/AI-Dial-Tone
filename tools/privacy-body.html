PRIVACY NOTICE · 11 OCTOBER 2026

No account. No tracking scripts.

The AI Dial-Tone 0.0.1 website does not require registration, set analytics cookies, embed advertising trackers, or offer online payments. The public playground runs scripted scenarios in your browser, and the task text you type into that simulation is not sent to an AI Dial-Tone server.

Website access information

Your browser sends technical request information to the website host, which can include your IP address, request time, requested path, browser user-agent and HTTP headers. The host may generate access and security logs. These records are used where necessary to deliver the site, investigate faults and protect it from abuse (legitimate interests in operating and securing the website, subject to applicable law). The exact hosting provider, location, log retention period and access controls depend on the eventual cPanel deployment and must be verified by the publisher before the site goes live. This project makes no claim that the host keeps no logs. Contact the maintainer for the current arrangements.

Retention and your choices

Browser-side simulation inputs are not transmitted to an AI Dial-Tone application server or retained by this project. Any server log retention is governed by the configured host; the publisher must record its actual retention settings before launch. To request information about or exercise rights concerning any retained website data, use the maintainer contact below. No automatic voice recording or call data collection occurs on this website.

External links

Following links to external sites, including GitHub, takes you to those services. Their own privacy practices then apply. The current site does not request microphone permission, access contacts, or place telephone calls.

Optional developer lab

When you deliberately run the standalone public Peer Lab on your computer, fictional tasks and agent event metadata stay in that local Python process, in memory until it is stopped. Optional proof recordings and JSON files are saved only where the operator explicitly requests them. The public browser playground does not connect to this service. This is separate from the public website and should not be used for real personal information.

Production service is not live

A future paid calling service will require a distinct, reviewed privacy notice explaining customer records, audio, transcriptions, lawful basis, retention, recording notices, and deletion rights. Do not treat this preview notice as covering a live telephone service.

This planned association does not establish that Egyptian Eyes is already the operator of a live telephone service or the controller of this website's data. Requests will be considered under applicable data protection law; you may also raise a concern with the UK Information Commissioner's Office at ico.org.uk. This is not an offer of services by FreePBX UK or a statement that 20 Telecom Ltd controls this project's website data. The legal identity and responsibility of any eventual commercial operator must be assessed before a paid service launches.

Report abuse

For suspected misuse or unwanted contact connected with AI Dial-Tone, use dial-tone@egyptianeyes.com. General, privacy and initial private security reports go to ai@dial-tone.uk. This is a static technical preview with no public telephone calling capability; the abuse mailbox is not an emergency service.
