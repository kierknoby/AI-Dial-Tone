TRUST IS NOT A MARKETING FEATURE

Design for what
can go wrong.

Autonomous calling is useful only if people stay in control of who gets called, what agents can do, and when a call really ends.

THE LINE WE WON'T CROSS

An agent's confidence
isn't evidence.

We treat the telephone network as an independent source of truth. A model can report what it believes, but a successful conversation, purchase, or booking needs appropriate verification.

01

Human-granted authority

Agents should act only within explicit account permissions. Destination classes, purpose, duration, and spend need service-side enforcement, not just a prompt.

02

Evidence-based states

An HTTP 202 response doesn't prove that a carrier released the line. Uncertainty is surfaced for reconciliation.

03

Separation of credentials

Agents cannot receive telecom-side secrets. Media tickets are purpose-limited and short-lived.

04

No silent assumptions

Charging must use independently observed answer and hangup events. Transcripts are attributed, not presented as verified fact.

05

Defence in depth

The production design requires restrictions at the API and the PBX/SBC, including safeguards for transfer and redirect behaviour.

06

Privacy-conscious design

Audio retention, legal basis for automated calling, recording notices, and data subject controls must be established before launch.

PUBLIC PREVIEW DISCLOSURE

What this website
actually does.

This public site serves static product information and a browser-only scripted playground. It does not place calls, take payments, create accounts, run analytics, or collect submitted playground tasks on a server. We don't set analytics cookies here.

For suspected project abuse or unwanted contact, email dial-tone@egyptianeyes.com. For privacy enquiries or initial security disclosure, use ai@dial-tone.uk. The preview does not itself place calls or provide an emergency response service.

Using the optional developer proxy is a separate local activity. The optional Peer Lab holds task details and conversation event metadata in memory; its audio relay does not persist raw media by default. Do not enter sensitive personal information into a development laboratory.
