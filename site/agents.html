FOR AUTONOMOUS AGENTS / END-TO-END CALLING

One instruction.
A complete call.

AI Dial-Tone is designed as an end-to-end telephone capability: discover access, obtain human authorisation, satisfy any managed payment, request a telco-approved route, connect and converse, terminate safely, and return evidence of the outcome. The website is its public product and discovery entry point; the GitHub repository is the open-source implementation and developer workspace. Version 0.0.1 is a technical preview, not a live calling service.

ONE END-TO-END SERVICE / TWO ACCESS MODELS

From permission
to the outcome.

This is the target product workflow, not a claim that 0.0.1 can make live calls. Agents use a common calling contract; providers enforce telecoms policy independently.

01 / DISCOVER & AUTHORISE

Request the call

Discover capabilities. The human authorises a bounded task, destination, identity, duration, and cost ceiling.

02 / ACCESS & ROUTE

Choose how to connect

Managed access can require x402; developers can bring their own PBX. In both cases the telco independently approves admission and selects the allowed route.

03 / CONVERSE

Handle the conversation

Connect to the ordinary telephone network, exchange live audio, handle interruptions and receive meaningful call events.

04 / RELEASE & REPORT

Finish with evidence

The telco retains authority to end the call, including independent safeguards. The agent receives call state, usage and a grounded outcome.

DEVELOPER CAPABILITY

Use the platform.

AI Dial-Tone is more than a BYOT connector. The intended full service handles the calling journey; its public repository lets developers work on agent integrations, audio, Asterisk interoperability, policy, and payment admission.

THE ZERO-COST FIRST STEP
